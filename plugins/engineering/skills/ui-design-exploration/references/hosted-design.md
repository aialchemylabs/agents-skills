# Optional hosted design integration

The maintained Superdesign skill describes a separate authenticated design service. Before using it, inspect the installed tool/version and supported capabilities. Require an account and authorization that cover the selected service, generation costs and the actual source/assets sent. Existing authorization need not be requested again.

Prepare the smallest useful context: relevant route, components, tokens, representative states and permitted assets. Exclude secrets, unrelated files and private customer content. Record the context revision so later work does not silently reuse a stale design system. Avoid automatic whole-repository uploads.

For an existing screen, establish a faithful baseline before branching alternatives. Keep replacement and exploration distinct. Return actual artifact identifiers and the selected direction's implementation context. If the service or credentials are unavailable, use available local design facilities; never pretend a hosted draft exists.

# Prepare a reviewable PR

Find an existing PR for the branch before creating another. Resolve its real base and compare the final diff against that base, including generated files and changes inherited from other authors. Confirm that the implementation still addresses the requested problem.

Run repository-required checks for the final changes. For UI work, include the repository's required screenshots or scoped motion evidence. Never imply that an unavailable check passed.

Write the title and description around the resulting behavior, relevant verification and material limitations. Follow the repository template and attribution convention. Do not copy a universal bot signature, reviewer vendor preference or draft policy from another project. Upload evidence only to an authorized destination and keep temporary evidence out of source history unless the project owns it.

Inspect the exact staged diff, author identity, target branch and destination before publishing. Preserve author/coauthor credit. Once authorized, create or update the PR and use the host's linking facility if required.

# Product Delivery

Resolve the exact repository and owning task. Translate the requested outcome into acceptance examples, including error, empty, permission and recovery states. Establish the baseline and work in the assigned worktree. Keep task scope and branch identity in the durable handoff.

Implement across the necessary frontend, backend and shared contracts. Use the relevant frontend, API and testing skills. Run focused behavioral tests and an integrated client check for user-facing flows. Record exact commands, results, changed files, commit and remaining limitations.

Provide a bounded diff to the council only when its configured inference policy covers that review. Finish with the tested artifact and handoff; a deployment or release is complete only after its actual acceptance checks.
